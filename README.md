# Digital Tales, édition commerciale : dernière version

`/mise-a-jour-digital-tales` installée chez chaque licencié pour savoir si une version plus
récente de l'édition existe.

Il ne contient aucun fichier de l'édition ni aucun lien de téléchargement : ceux-ci sont remis
personnellement à chaque licencié. Contact : hello@digitaltales.studio
